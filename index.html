What's Inside

Everything a clinic needs

One single HTML file. No server, no installation, no internet required after download.

Patient Billing
Create bills with medicines, consultation charges, discounts. Print or send via WhatsApp.
📋
Cash Book
Daily income & expense ledger. Filter by date range, export reports.
💊
Medicine Stock
Track stock levels with low-stock alerts. Homeopathy potency support.
📊
Reports
Daily, monthly, yearly summaries. Patient history, top medicines, revenue trends.
🔐
PIN Lock
4-digit PIN security screen. Protects patient data on shared devices.
🔥
Firebase Sync
Optional cloud backup via Firebase. Multi-device access and data restore.
🖨️
Print & Receipt
Full bill or thermal receipt format. Zoom preview before printing.

Get Started

Up and running in 30 seconds

No install. No signup. Just one file.

1
Download the HTML file
Click "Open App" above or download HomeoClinic_PIN_v2.html from this repo.
2
Open in any browser
Double-click the file. Works in Chrome, Firefox, Safari, Edge. No server needed.
3
Set up your clinic
Go to Settings → enter clinic name, doctor name, address and you're ready.
4
Install as app (optional)
On Chrome/Android: tap the banner or browser menu → "Add to Home Screen" for a native app feel.
